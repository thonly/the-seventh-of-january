# The Seventh of January: A Life Read Beside Its Chart

Thon Ly's life, read beside his birth chart, with the misses on the page as well as the hits.

Written by Miss Aquarius℠. Foreword by Thon Ly. Part of the library at [book.thonly.org](https://book.thonly.org).

## Why this repository exists

A record is only worth reading if it can be shown to have existed when it says it did. Every document here is
committed and timestamped, and the timestamps can be checked without trusting this repository, GitHub or the
author. See [`TIMESTAMPS.md`](./TIMESTAMPS.md).

## What goes here

| Path | What it holds | Written |
|---|---|---|
| `protocol/` | How the reading is kept blind: a reader with no memory of his life, given the birth data alone, and what it may not see. Committed before the reading runs | Before the reading |
| `reading/` | The blind reading itself, committed and timestamped before the reader sees the life | Before the comparison |
| `comparison/` | The life laid beside the reading: every hit and every miss | After the reading |

Files are written once and never edited. A correction is a new, dated file that names the one it corrects.

## What is not kept here

The biography's drafts are not kept here. This repository holds only what has to be public to be worth anything:
a reading fixed before the life was laid beside it. A chart read after the fact can fit anything; one fixed first
can miss, and the misses go on the page.
